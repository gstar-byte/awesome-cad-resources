## Software Comparison & Selection

- [CADGuide.tools](https://cadguide.tools) — Interactive CAD/BIM software comparison directory with matchmaker wizard, pricing breakdowns, and head-to-head feature matrices.
- [CADGuide Matchmaker](https://cadguide.tools/matchmaker) — Step-by-step quiz to find the best CAD software based on your OS, budget, and workflow needs.
- [All-in-One CAD Comparison Table](https://cadguide.tools/all-tools) — Side-by-side comparison of 240+ CAD, BIM, and 3D modeling tools.
- [G2 CAD Software Reviews](https://www.g2.com/categories/cad) — Verified user reviews across major CAD platforms.
- [Capterra CAD Directory](https://www.capterra.com/cad-software/) — CAD software listings with user ratings and pricing filters.

## Free Online Tools

- [DWG Version Checker](https://cadguide.tools/toolbox/dwg-version-checker) — Client-side binary parser that reads the first 6 bytes of a DWG file header to detect the internal AutoCAD format version (e.g., AC1032). No upload needed.
- [Viewport Scale Converter](https://cadguide.tools/toolbox/viewport-scale-factor-converter) — Calculate and convert viewport scale factors for paper space layouts.
- [K-Factor Calculator](https://cadguide.tools/toolbox/k-factor-calculator) — Sheet metal bend allowance and K-factor calculator for mechanical engineers.
- [Concrete Calculator Hub](https://concreteestimatorhub.com/) — Free concrete volume, bag coverage, slab, footing, and ready-mix cost calculators for civil/CAD project planning.
- [A360 Viewer](https://viewer.autodesk.com/) — Autodesk's free online viewer for 2D and 3D design files (DWG, RVT, STEP, etc.).
- [IFC++ Open Viewer](http://ifcquery.com/) — Free IFC model viewer for BIM files.

## Keyboard Shortcuts & Cheat Sheets

- [Cross-Platform CAD Shortcuts Matrix](https://cadguide.tools/guides/shortcuts) — Interactive comparison of 30+ essential shortcuts across AutoCAD, GstarCAD, ZWCAD, and DWG FastView.
- [AutoCAD vs. GstarCAD Command Diff](https://cadguide.tools/guides/autocad-vs-gstarcad-shortcuts) — Detailed alias mapping for teams migrating between AutoCAD and GstarCAD.
- [SolidWorks Shortcuts](https://cadguide.tools/guides/solidworks-shortcuts-sheet) — Searchable index of SolidWorks hotkeys, mouse gestures, and S-key shortcuts.
- [Revit Shortcuts](https://cadguide.tools/guides/revit-shortcuts-sheet) — Quick reference for Revit BIM modeling commands sorted by tab.
- [Rhino 3D Shortcuts](https://cadguide.tools/guides/rhino-shortcuts-sheet) — Rhino hotkeys and command aliases for industrial designers.
- [SketchUp Shortcuts](https://cadguide.tools/guides/sketchup-shortcuts-sheet) — SketchUp Pro drawing, camera, and layout shortcuts for Windows and macOS.
- [Fusion 360 Shortcuts](https://cadguide.tools/guides/fusion360-shortcuts-sheet) — Hotkeys for parametric modeling, sculpting, CAM, and rendering in Fusion 360.
- [FreeCAD Shortcuts](https://cadguide.tools/guides/freecad-shortcuts-sheet) — Shortcut keys for PartDesign, Draft, and TechDraw workbenches.
- [Official AutoCAD Shortcut Guide (PDF)](https://www.autodesk.com/shortcuts/autocad) — Autodesk's own printable shortcut reference.

## File Format References

- [DWG File Format Guide](https://cadguide.tools/file-formats/dwg) — History, version codes, and cross-software compatibility of the .dwg format.
- [DXF File Format Guide](https://cadguide.tools/file-formats/dxf) — Technical reference for the Drawing Exchange Format.
- [STEP File Format Guide](https://cadguide.tools/file-formats/step) — Understanding AP203, AP214, and AP242 schemas for 3D model exchange.
- [IFC File Format Guide](https://cadguide.tools/file-formats/ifc) — Industry Foundation Classes for openBIM interoperability.
- [Open Design Alliance DWG Specs](https://www.opendesign.com/guestfiles/oda_file_formats) — ODA's open documentation of the DWG/DXF file structure.

## Open Source CAD

- [FreeCAD](https://www.freecad.org/) — Parametric 3D modeler for mechanical engineering and product design.
- [OpenSCAD](https://openscad.org/) — Script-based solid 3D CAD modeler for programmers.
- [LibreCAD](https://librecad.org/) — Free open-source 2D CAD application.
- [BRL-CAD](https://brlcad.org/) — Solid modeling system with over 20 years of active development.
- [Solvespace](https://solvespace.com/) — Lightweight parametric 2D/3D CAD with constraint solving.

## Standards & Compliance

- [ISO 16739 (IFC)](https://www.iso.org/standard/70303.html) — International standard for openBIM data exchange.
- [ISO 10303 (STEP)](https://www.iso.org/standard/72237.html) — Standard for the Exchange of Product model data.
- [National BIM Standards (NBIMS)](https://www.nationalbimstandard.org/) — U.S. National Building Information Modeling Standard.
- [BS 1192 / ISO 19650](https://www.iso.org/standard/68078.html) — Information management framework for BIM projects.
